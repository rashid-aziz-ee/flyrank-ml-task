Evaluating Random Forest Anomaly Classifiers Against Rule-Based Baselines for Organic Search Telemetry

Author: Rashid Aziz | Machine Learning Track

Abstract: This research evaluates machine learning approaches for detecting organic search discoverability anomalies using telemetry datasets. We define a baseline heuristic rule based on positional drops and impression variance, compare it against a trained Random Forest classifier, and perform temporal out-of-time validation. Our findings indicate that non-linear ML models reduce false-positive audit alerts on newly indexed pages compared to static baseline rules. Finally, we convert model outputs into a human-in-the-loop content action playbook.

1. Introduction / Problem Statement

High-velocity web search infrastructure requires early identification of discoverability drops. Traditional rigid baseline rules often generate false positives due to site migrations or natural rank bouncing. This paper addresses whether a machine learning model evaluated under strict temporal validation can reliably directionalize content audit resources.

2. Data & Feature Contracts

Evaluation was conducted on standard anonymized search telemetry splits (month=2026-03). Public-safe features include trailing 7-day impression variance (impression_std_7d), 30-day position averages, and position momentum ratios. All private domain identities and sensitive tokens were excluded.

3. Methodology & Validation Design

We implemented a Random Forest classifier ($n=100, \text{max\_depth}=5$). To prevent data leakage common in standard K-Fold splitting, evaluation was strictly performed using TimeSeriesSplit out-of-time folds.

5. Limitations & Honest Framing

The model is intended strictly for directional decision-support. Performance degradation was observed on brand-new pages (age < 30 days), requiring explicit human review rules.

6. Ranked Content Action Playbook

Model scores map directly to operational actions: REFRESH_CONTENT (Score ≥ 80), TECHNICAL_AUDIT (Score 50–79), and NO_ACTION (Score < 50), with mandatory human overrides for new pages.
